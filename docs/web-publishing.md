# 构建与发布

先运行 npm test、npm run check:public、npm run build:pages。构建只复制显式运行清单到 _site，不复制文档、测试、私有证据和密钥。新增页面需更新允许清单。

main 为网页、xhs 为小红书、vx 为微信。共用更新同步三分支，平台专属配置留在对应分支。此模板没有配置自动部署和真实站点；Git 推送不等于发布。

在干净 worktree 对固定 SHA 重跑检查，从 _site HTTP 服务进行真实输入验收，然后使用项目自己的平台工具上传产物。记录源码 SHA、部署 ID、正式 URL、结果、HTTPS/子路径/缓存核对和未测设备。

公开前检查昵称、联系方式、AppID、密钥、私有 URL、本机路径、真实机制与专属素材。check:public 只提供常见模式和本仓库禁止项扫描，仍需人工审查。

本次只清理当前目录，没有重写历史；已有公开提交中的旧内容仍可访问。删除文件不能撤回已公开数据。
