# UI 总规范

- [home](home.md)：主界面：显示已接入项目及可用状态；无素材时用文字占位。手机和微信操作语义一致。
- [entry](entry.md)：加载与准备：图片解码、音乐等待和失败重试；阵容、分工、章节与开始。点击开始解锁音频，不自动请求全屏。
- [battle-hud](battle-hud.md)：战斗：本体/护盾/资源分开显示，时间、倍速、团队、当前/下一轮、点名、目标、冷却、日志、暂停和导航。团队桌面左下，触控左上，五人单列十人双列。
- [pause](pause.md)：暂停：继续、重开、主页、音量、日志、练习设置、可用时手动全屏。冻结模拟、清输入，关闭日志不自动继续。
- [music-player](music-player.md)：音乐：播放暂停、音量、曲目、进度及错误恢复。按媒体时间推进，跳机制不切曲，重开/失败重试重置。没有获授权音频时明确无音乐。
- [prompts](prompts.md)：提示：谁→目标/方位→动作→时机/次数；PC 键位与触控动作分别生成。过期提醒随真实状态清除，颜色之外保留形状/文字。
- [result-and-log](result-and-log.md)：结果：胜利动画仅一次后弹窗；失败说明轮次和条件；资料截止不宣称击杀。日志包含战斗时间、eventId、队伍/格位、动作和结果，可导出。查看战场保持终态。

全部屏幕覆盖 PC、横屏手机、平板、微信小游戏及竖屏暂停。文字和按钮用 CSS px，避让安全区/摇杆，弹窗不透传；DOM 与 Canvas 可适配布局但不能缺少功能。检查 1440×900、844×390、667×375、568×320。真实设备与模拟器结果分别记录。
